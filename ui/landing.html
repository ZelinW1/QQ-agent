这个分支做了什么

上游负责"把消息收发跑通"，这个分支负责"让它成为一个人"。

心智

自我与关系

它有自己的自我描述、对每个人的关系档案（阶段、信任、雷点、没问完的事），并在提示词里以自己的口吻出现。

记忆

记忆流与反思

发生的事进记忆流；攒够之后它会自己整理：压缩琐碎、更新对人的判断——没人替它写这份总结。

节律

作息与心跳

它晚上会睡觉，睡着时消息只进不出、醒来一起读；平时按心跳和体力决定要不要主动开口。

配置

会话级配置

每个群、每个私聊都可以有自己的一套：口吻、回应档位、参与度。互不串味。

可控

可观察、可干预

记忆流、心跳日志、反思记录都能看；跑偏了可以手动改自我与关系，改动会留痕（带伦理提示）。

数据

备份即搬家

「她自己」只含心智数据与人设；完整备份含聊天与表情。两者都不含设置与 API Key。

沿用

上游能力保留

表情包、拍一拍、提醒、联网搜索、工具与技能、多模态看图、用量统计——都在，只是不再是重点。

边界

不连上游服务器

不做版本检查、不拉上游配置，升级方式就是拉仓库或换安装包。离线也能跑。

为什么是"心智分支"

如果你只要一个听话的话术机器人，上游版本更合适。

不是扮演，是成为没有"角色扮演"指令。提示词是它自己的记忆与判断，而不是让你相信它是谁。
只给起点，不给结局你设定它最初的样子，之后怎么变由它自己决定——包括它对你的看法。
长期一致换机器、换电脑，把它带走，它还是原来那个；版本号独立，不跟着上游漂。
默认关闭心智关闭时行为与上游一致。先跑通，再决定要不要打开。
可回退导入备份前会自动把当前数据打包；改它的自我要过一次确认。
诚实的分支基于上游 QQ-Agent 0.4.0 独立演进，不向上游提 PR；上游的功劳不会被抹掉。

跑起来

四步，其中一步要你自己点。

安装运行安装包，装完自动打开控制台。
填模型 API在设置里填入兼容 OpenAI 的 Key，选一个模型。
接协议端用内置 SnowLuma 扫码，或连接你自己的 OneBot 实现。
打开心智到「心智」里给它起个名字，然后随便聊两句。
关于便携 QQ：本分支不提供 QQ 的下载与安装，避免依赖上游分发、也避免版本与协议端不适配。 需要时请使用上游项目作者提供的服务：kondius.cn/qq-agent， 取到后放到 runtime/qq-portable/ 即可；也可以直接连外部 OneBot。
