# QQ Agent · 洄

![平台](https://img.shields.io/badge/platform-Windows%20%7C%20Electron-lightgrey)
![技术栈](https://img.shields.io/badge/stack-Node.js%20%7C%20原生前端-orange)
![测试](https://img.shields.io/badge/tests-50%20suites-brightgreen)

一个跑在你自己电脑上的 QQ 伙伴。

它不是一个"按人设说话"的机器人：有自己的自我描述、对每个人的关系、会自己整理记忆，
晚上会睡觉，睡着时消息只进不出、醒来一起读。你给它的不是剧本，是一个起点。

> **名字**：「洄」取自洄游——鲸类长途往返、年年回到同一片海。
> 长期、往返、始终是同一个，这是这个分支想做的事。
> （名称创意来自 deepseek v4.1 flash。）

## 设计理念

**1. 不是扮演，是成为。**
提示词里没有"你要扮演一个……"。写进去的是她自己的记忆与判断：
她记得谁、在意什么、昨天谁说了什么。她不是在演，是在用已有的经验回应。

**2. 只给起点，不给结局。**
你设定她最初的样子（名字、形象、说话习惯、硬规矩），之后性格怎么变、对谁更亲近，
由她自己在相处与反思里决定——包括她怎么看你。

**3. 记忆归她自己。**
别替她写总结。她能自己记事、自己整理、自己修正对人的判断；
引擎只提供工具和时机制，不预设结论。

**4. 可观察，也可回退。**
记忆流、心跳日志、反思产出都能看；跑偏了可以手动改，但改动会留痕，
而且改之前会问你一句：这是她已经有过的自我，确定要动吗？

**5. 默认关闭。**
心智关闭时，行为与上游版本一致。先跑通，再决定要不要让她开始记事。

## 她是怎么运作的

**一次运行 = 一次独立会话（沿用上游架构）**
每条（批）消息新开一次运行：重新组装提示词 → 调模型 → 跑完即弃。
LLM 层面零历史，单次成本恒定。所以"她记得什么"完全取决于落盘的东西。

**四层心智数据**（`data/mind/`）

| 层 | 内容 |
|---|---|
| 事件 | 发生过的事，带时间、参与者、重要度 |
| 关系 | 对每个人的阶段 / 信任 / 亲近 / 知道什么 / 雷点 / 没问完的事 |
| 自我 | 她对自己的描述、心情、挂心的事（带版本与 changelog） |
| 节律 | 体力、当日行为计数、作息状态 |

**提示词分层**（`src/prompt-layers.js`）
安全在最前，身份（charter）在 system，情景（本次消息）在 user，技能在中间。
心智内容以她自己的口吻接在 system 里，和情景分开——前缀稳定，缓存才有效。

**会睡觉**
到点后进入睡眠：消息照常入库，但不唤醒、不决策、不回复；醒来把积压当一批读。

**会反思**
攒够一定条数的事件后，她会自己整理：压缩琐碎、更新对人的判断。
阈值、冷却、每日上限都可以调（默认 8 条 / 120 分钟 / 8 次）。

## 这个分支做了什么

### 心智：自我与关系

- 她有**自我描述**（会随反思改写，带版本与 changelog）、心情、挂心的事
- 对每个人有**关系档案**：阶段、信任、亲近、知道什么、雷点、还没问完的事
- 四个工具：`remember_event` / `update_relation` / `self_revise` / `recall`
- 旧版的"群友印象"已并入关系档案，不再有两套互相矛盾的说法

### 节律：作息、心跳、体力

- **作息**：入睡/醒来时间、每晚抖动、一晚最多再撑几次、安静多久才睡
- **体力**：上限、每小时恢复、低于阈值就不动
- **心跳**：间隔与抖动、每日决策上限、每日主动次数、多久没聊才会主动
- 一切都可在 **心智 → 节律** 里调，带单位、范围与说明，还有「恢复默认」

### 可观察：记忆流与心跳日志

- **记忆流**：她记下的事，可按人/按会话筛选
- **心跳日志**：最近心跳（内存，含"跳过"及原因）+ 已落盘的行动，可一键清空日志文件
- **反思状态**：未反思事件数 / 阈值 / 冷却到几点 / 今日次数，还有「立即反思」按钮

### 可以说"不"，但会留痕

- 自我描述、每段关系的阶段/信任/亲近/称呼/雷点都能手动改
- 改之前弹确认：*改它等于改写已经经历过的自我，不建议像基因编辑那样动*
- 自我记 `by: owner` 进 changelog；关系记 `evidence: owner:manual`
- 存储层的钳制照旧（阶段一次一级、信任单次 ±10）——手动编辑不是后门

### 备份：换机器她还是原来那个

| 包 | 内容 | 不含 |
|---|---|---|
| **她自己** | `mind/` + 人设（名字/charter/参与度/群友备注） | 聊天记录、设置、密钥 |
| **完整备份** | 上面 + 聊天记录、会话留档、表情、用量 | **设置与 API Key** |

导入前会自动把当前数据打包到 `data/backups/`，导错了可以回退；
还原只写白名单目录，`config.json` 即使被塞进包里也会被忽略。

### 界面

- **心智**：状态 / 节律 / 身份 / 记忆流 / 会话配置
- **记录**：会话过程 / 消息存档 / 用量 / 心跳日志
- **设置**：运行配置 / 工具与技能 / 插件 / OneBot

每个群、每个私聊都可以有自己的**会话级配置**（口吻、回应档位、参与度）。

## 与上游的差异一览

**新增**：心智（自我/关系/记忆流）、反思、作息与心跳、体力、会话级配置、
手动编辑（带留痕与伦理提示）、备份与导入、心跳日志、心智默认关闭的安全阀。

**保留**：无状态会话与按次计费、响应档位、表情包、拍一拍、提醒、联网搜索与看图、
工具与技能、白名单、屏蔽名单、用量统计、OneBot 协议端接入。

**移除**：
- 社区相关入口（Skill 市场 / 人设广场 / 金句上传 / 意见箱 / 群二维码彩蛋）
- 应用内更新检查（分支不连任何更新服务器）
- 协议端的自动下载与安装（改为自行准备，见「快速开始」）
- QQ 的自动下载与安装（见下方"便携 QQ"）
- 旧的"群友印象"体系（已并入关系档案）
- 整段角色卡作为默认形态（保留兼容，默认走分槽身份）

## 快速开始

### 0. 准备协议端

本项目**不代为下载、分发或安装**协议端，也不代管它的进程、不读取它的账号目录。

请自行选择并按其官方说明安装、配置、启动一个 **OneBot v11** 协议端
（需要正向 WebSocket 事件接口 + HTTP API），完成 QQ 登录后，
在「设置 → OneBot 连接」里填写两个地址与各自的访问令牌。
第三方程序与 QQ 客户端的版本要求、使用许可与风险，以对应项目的说明为准。

### 方式一：安装包（Windows）

下载 `QQ-Agent-Hui-V0.5-Setup.exe`（见 Releases），安装后启动控制台。

### 方式二：从源码

```bash
npm install
npm run setup     # 只做环境检查（协议端/便携 QQ 都属可选项），不下载任何第三方程序
npm start
```

需要 Node.js ≥ 20。没有桌面环境时用 `npm run server`，再打开 <http://127.0.0.1:3210>。

### 便携 QQ

本分支**不提供 QQ 的下载与安装**。

需要时请使用**上游项目作者**提供的分发服务：<https://kondius.cn/qq-agent>，
取到后把 QQ 程序文件放到 `runtime/qq-portable/`（该目录下要能直接看到 `QQ.exe`）。
也可以完全不装，连接你自己的 OneBot v11 实现。

### 填模型

设置 → 模型 API：填 Base URL 与 Key，拉取模型列表后选定。

### 打开心智

心智 → 节律 → 打开「心智功能」。

之后随便聊两句，到 **心智 → 记忆流** 看有没有事件。
想看反思效果，在 **心智 → 状态 → 最近反思** 里点「立即反思」。
想让她会睡觉，回节律页打开「夜里会睡着」——注意「安静多久才睡」：
刚聊过天她不会立刻睡（默认 5 分钟）。

## 数据与隐私

- 所有数据在 `data/`：配置（含 API Key）、消息存档、心智数据、表情、备份
- 心智数据是她的记忆，**不会**随导出泄露密钥（备份包不含 `config.json`）
- 不连任何上游服务器：没有版本检查、没有遥测上报
- 分享部署副本前先脱敏：

```bash
node scripts/sanitize-release.mjs --dry-run   # 先看会清理什么
node scripts/sanitize-release.mjs             # 清空 Key / 白名单 / 存档 / 登录态
```
